# Bài tập CSS cơ bản — Tuần 3

Mở index.html để xem danh sách bài làm.

- Bài 2: giữ nguyên bài đã có.
- Bài 3: chọn phương án b (hoàn thành bài 4–7).
- Bài 4–7: HTML và CSS riêng cho từng bài, bám theo mẫu PDF.
- Bài 8: chọn phương án b, The Bat family. Vì không có tệp css2 gốc trong thư mục, dựng lại HTML theo hình mẫu. Ảnh nhân vật dùng ảnh mẫu nhúng trong PDF dưới dạng CSS sprite.
- Bài 9: trang icon Font Awesome, lưu thư viện và font trong dự án để dùng ngoại tuyến.
- Bài 10: index.html liên kết các bài và đã có đầy đủ họ tên, MSSV, lớp, ảnh cá nhân cùng liên kết Facebook.
